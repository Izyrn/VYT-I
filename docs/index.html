FAQ

Windows says "Windows protected your PC"

The game isn't code-signed yet, so SmartScreen shows a warning for new apps. Click More info, then Run anyway. You can read all of the source code on GitHub.

Does it need an install or an internet connection?

No. It is one portable .exe and runs fully offline. Saves are stored in a local database in your user profile folder.

It runs slowly. What can I do?

Press Esc then Settings (or F2 in game) and set Graphics to Low or Medium. Medium and Low also show fewer pedestrians and cars.

Is it a copy of another game?

No. The map, cars, people, buildings, sounds and music are all original and generated by code.

Can I get it for Mac or Linux?

Not yet - the game is built with Electron, so you can run it from source with npm install and npm start on any platform. Instructions are in the README on GitHub.
