# VYT 1

An open-world driving game for the desktop, built with **Electron + Three.js** (the same Chromium engine as Edge).
Everything - the 8 km map, cars, people, buildings, sounds and radio - is generated by code; there are no art or audio assets.

## Run
```
npm install
npm start
```
`npm run dist` builds a portable Windows exe in `dist/`. `npm run icon` regenerates `build/icon.png`.

## What's in it
- Realistic-ish vehicle physics (manual/auto gearbox, tyre grip, drifting, suspension, fuel, crash damage and dents), 4 cars + van, pickup, supercar, motorcycle and boat, and a flyable plane.
- Procedural map: downtown with enterable towers, residential area, towns, desert, mountains, river with a bridge, tunnel, airport, parking garage, 28 fuel stations.
- Day/night cycle, weather (rain, fog, storms), post-processing (bloom, grading, speed blur), reflections, wet roads.
- Traffic with signals, pedestrians that look for cars, police, roadside assistance.
- Economy: jobs, robberies, street races, drift challenge, taxi shifts, levels, hunger/energy, shops, wardrobe.
- Homes: free starter apartment, apartments from $5k, houses and villas with interiors, laptop and phone.
- Local SQLite save (`vyt1.db` in your app-data folder).

## Controls
W/S throttle/brake - A/D steer - Space handbrake - I ignition - T auto/manual - Q/E shift - L lights - Z/X/V indicators - H horn - C camera
N radio - U wipers - G get out/in - F interact - P phone - M map - R rob - J delivery - Esc pause/settings - F2 quality
Plane: Shift/Ctrl throttle, W/S pitch, A/D roll, Q/E rudder, Space brake.

## Layout
- `electron/` main process, preload, SQLite (sql.js)
- `src/` game code: `world.js`, `car.js`, `carmodel.js`, `human.js`, `interior.js`, `traffic.js`, `police.js`, `events.js`, `flight.js`, `menus.js`, `main.js` ...
- `tools/` icon generator
